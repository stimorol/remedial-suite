# 學習扶助智慧整合平台 (Remedial Suite)

> 一站式整合「學習扶助測驗診斷分析」與「課程規劃日誌生成（A4 擬真公務排版）」

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live%20Demo-blue?style=flat-square&logo=github)](https://stimorol.github.io/remedial-suite/)

---

## 專案緣起與簡介

本系統為彰化縣三春國民小學黃奕豪主任設計之「學習扶助」教學行政輔助工具。先前系統分為兩個獨立網頁：
1. **學習扶助測驗分析工具 (`remedial-tool`)**：負責上傳評量 CSV 報表並診斷勾選需加強之基本學習內容。
2. **學習扶助課程規劃與日誌生成器 (`course-planner`)**：負責排定課堂日誌與匯出標準 A4 PDF。

為了免去教師在兩套工具間手動切換與複製貼上的繁瑣流程，本專案將兩者整合成一體化平台：
* **步驟 1**：匯入測驗報表並勾選學生未通過之教學目標。
* **一鍵連動**：點擊「帶入步驟 2 課程規劃表」，系統自動將科目、教學目標及代碼直接注入日誌系統。
* **步驟 2**：智慧日曆排程自動帶入課堂日期，並以擬真 A4 雙頁預覽即時排版，支援一鍵匯出高解析度 PDF。

## 主要核心特色

### 1. 測驗診斷分析 (Step 1)
* **智慧表頭與編碼識別**：自動偵測 Big5 與 UTF-8 編碼，彈性對應測驗報表各欄位。
* **快速批次選取**：支援「2人以上未通過」、「3人以上未通過」快速一鍵勾選。
* **無縫銜接**：一鍵將勾選的教學目標自動格式化並轉發至步驟 2。

### 2. 課程規劃與日誌排程 (Step 2)
* **官方格式樣板動態防呆**：
  * 「數學 - 寒暑假學扶班」限定「暑假」、「寒假」。
  * 「數學 - 學期中學扶班/原班」限定「第一學期」、「第二學期」。
  * 「國語」與「英語」全學期自由選擇。
* **一至九年級複選**：支援混齡與跨年級輔導班，自動格式化呈現於官方報表。
* **結構化上課時段**：週一至週日點選複選搭配時間選擇器，杜絕手填格式錯亂。
* **智慧日曆排程演算法**：
  * 開課日期預設自動讀取當前今日日期。
  * 結課日期依學期型態自動推算（學期中 +20 週、暑假 +8 週、寒假 +4 週）。
  * 支援依每週授課星期與總節數批次自動排定所有課堂日曆日期。
* **教學目標防重複機制**：同一堂課已選入之目標自動標示 `[已帶入]` 並鎖定，文字手動刪除即時解鎖。

### 3. 公務級 A4 擬真即時預覽與 PDF 下載
* **智慧分頁排版**：完全比照教育部學習扶助標準格式，自動計算表格高度並精準跨頁。
* **換行格式化**：教學目標與策略換行維持獨立行排列，清晰整齊。
* **高解析度向量輸出**：採用 `html2pdf.js` 生成可直接列印呈報之標準公務 PDF。

### 4. 使用者體驗與資安承諾
* **深淺色模式無縫切換**：深色模式經過專門對比度校正，日期與時間選擇器清晰可見。
* **字體大小快速切換**：支援小、中、大三段字級縮放，保護教師視力。
* **100% 本地端瀏覽器運算**：所有學生個資與成績均在使用者瀏覽器本地處理，絕不上傳外部伺服器。

## 本地開發與使用

本專案為純靜態單頁應用（SPA），無需配置後端伺服器或 Node.js 環境：

```bash
git clone https://github.com/stimorol/remedial-suite.git
cd remedial-suite
# 直接使用任何瀏覽器開啟 index.html 即可使用
```
